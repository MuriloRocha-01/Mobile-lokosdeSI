3. Dados: ação até o servidor

sequenceDiagram
  actor U as Usuário
  participant S as Screen
  participant A as api.ts
  participant SRV as Servidor (mesmo do desktop)
  participant W as widgets / reminders
  U->>S: lança / edita / apaga transação
  S->>A: chamada autenticada
  A->>SRV: HTTP
  SRV-->>A: dados
  A-->>S: resultado
  S->>W: refreshWidgets() / syncReminders()
  S-->>U: lista atualizada (financeKey / agendaKey)
